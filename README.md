# Pong!ish

A ridiculous, two-player Pong game that runs in the browser with no build step.

## Play

Open `index.html` in a modern browser, or visit the deployed [GitHub Pages game](https://jjgerard.github.io/start-ai-project/). Drag anywhere on the left or right half of the arena to move that side's paddle. Both players can play at once on touchscreens. First to seven points wins.

Sound effects are synthesized in the browser and can be switched off with the sound button.

## GitHub Pages

The Pages workflow publishes the static site on pushes to `main` and `jjgerard-pong-mobile-game`, and can also be started manually from the Actions tab. Enable GitHub Pages with **GitHub Actions** as the build and deployment source in the repository's Pages settings.

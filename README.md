# Little Games Arcade

A small collection of browser games that runs with no build step.

## Games

- Open `index.html` in a modern browser, or visit the deployed [GitHub Pages arcade](https://jjgerard.github.io/start-ai-project/).
- Choose **Pong!ish** to play two-player Pong. Drag either half of the arena to move that side's paddle. Both players can play at once on touchscreens; first to seven points wins. Sound effects can be switched off with the sound button.
- Choose **Tic-Tac-Toe** for a two-player game on the same device. X goes first; use **New game** to reset the board.

## GitHub Pages

The Pages workflow publishes the static site on pushes to `main` and `jjgerard-games-landing-and-tic-tac-toe`, and can also be started manually from the Actions tab. Enable GitHub Pages with **GitHub Actions** as the build and deployment source in the repository's Pages settings.
